# Bota: единый ИИ-маскот

Один персонаж для всех ИИ-ассистентов компании. Тело, звезда в руках, глаза-радиоволны и анимации у всех одинаковые. Под клиента меняются аксессуары и цвета.

| Вариант | Атрибут | Аксессуары | Палитра |
|---|---|---|---|
| **Bota** (базовый) | `variant="bota"` | тюбетейка с орнаментом «қошқар мүйіз» | синяя звезда → красная |
| **Oscar** (Oscar Clinic) | `variant="oscar"` | 3D-персонаж: очки, стетоскоп, светящаяся звезда | золотая звезда → красная |

Живое демо: откройте `index.html` в браузере.

### Oscar: файлы

Oscar сделан из вашего 3D-рендера, разрезанного на слои: тело (`oscar/body.webp`, фон удалён) и отдельно звезда (`oscar/star.webp`). Кольцо-орбита, золотые звёздочки, свечение, блики в глазах и веки — анимированные накладки поверх. Папку `oscar/` кладите рядом с `bota.js`; если она лежит в другом месте, укажите путь: `<bota-assistant variant="oscar" assets="/static/oscar/">`.

Что делает Oscar:
- **покой:** парит и дышит, звезда плавает и покачивается в объёме, по орбите бегают огоньки, звёздочки мерцают, моргает;
- **думает:** звезда краснеет, разгорается и вращается, свет ярче, Oscar щурится от света, появляются ещё 10 звёздочек;
- **отвечает:** звезда пульсирует в такт «голосу», блики в глазах мерцают;
- **клик:** сплющивается, звезда подпрыгивает с поворотом, разлетаются звёздочки;
- блики в глазах следят за курсором.

Цвета Oscar: `--bota-accent` (свечение в покое), `--bota-accent-think` (свечение, когда думает), `--bota-think-hue` (насколько сдвинуть цвет звезды, по умолчанию `-42deg` = из золотого в красный).

## 1. Подключение (2 строки)

```html
<script src="/bota/bota.js"></script>

<!-- плавает в правом нижнем углу поверх сайта -->
<bota-assistant variant="oscar" floating></bota-assistant>
```

Без `floating` персонаж ведёт себя как обычная картинка: его можно поставить в шапку чата, на страницу, в логотип.

Размер задаётся так: `style="--bota-size: 64px"` (по умолчанию 120px, в режиме floating 88px).

## 2. Связь с вашим ассистентом

```js
const bot = document.querySelector('bota-assistant');

// клик по персонажу: откройте свой чат
bot.addEventListener('bota-click', () => openMyChat());

// когда ушёл запрос к ИИ
bot.setState('thinking');   // звезда плавно краснеет и разгорается, 4 звёздочки, щурится

// когда пошёл ответ (стриминг текста)
bot.setState('talking');    // глаза-волны двигаются как эквалайзер

// когда ответ готов
bot.setState('idle');       // парит, моргает, звезда снова синяя/золотая
```

Пример с `fetch`:

```js
async function ask(text) {
  bot.setState('thinking');
  try {
    const res = await fetch('/api/assistant', { method: 'POST', body: JSON.stringify({ text }) });
    bot.setState('talking');
    const data = await res.json();
    await printAnswer(data.answer);   // ваш вывод текста
  } finally {
    bot.setState('idle');
  }
}
```

Совет: поставьте второго персонажа в шапку окна чата (без `floating`, размер около 56px) и переключайте состояния у него. Тогда при открытом чате пользователь видит, как Bota/Oscar думает.

Другие методы: `bot.burst()` выпускает вспышку искорок, `bot.blink()` заставляет моргнуть.

## 3. Цвета

Всё меняется CSS-переменными, код трогать не нужно:

```css
bota-assistant {
  --bota-accent: #3B6CFF;        /* звезда в покое: основной цвет сайта */
  --bota-accent-think: #FF3B4E;  /* звезда, когда думает */
  --bota-line: #1F2350;          /* зрачки, рот */
  --bota-body: #FFFFFF;          /* тело */
  --bota-shade: #A9B6D3;         /* оттенок объёма и контура тела */
  --bota-blush: #FF9DB0;         /* румянец */
  --bota-gold: #D4A63A;          /* очки, лобное зеркало, крестик на шапочке */
  --bota-hat: #24307A;           /* бархат тюбетейки */
  --bota-ornament: #E8B931;      /* золотой орнамент и ободок тюбетейки */
  --bota-think-time: 1.6s;       /* скорость перехода цвета */
}
```

Для нового клиента: выберите `variant` (или задайте аксессуары напрямую) и впишите цвета его сайта.

## 4. Аксессуары вручную

Пресет можно переопределить:

```html
<bota-assistant variant="bota" glasses="round"></bota-assistant>   <!-- тюбетейка + очки -->
<bota-assistant variant="bota" hat="none"></bota-assistant>         <!-- без тюбетейки -->
```

- `hat`: `tubeteika` | `mirror` | `cap` | `none` (только для Bota)
- `glasses`: `round` | `none`

## 5. Что умеет

- **Покой:** парит и «дышит», моргает в случайные моменты (иногда дважды), звезда мягко пульсирует, 2 звёздочки мерцают.
- **Курсор:** глаза-волны следят за мышкой.
- **Клик:** сплющивается как желе, головной убор подпрыгивает, из звезды вылетают искорки, срабатывает событие `bota-click`.
- **Думает:** звезда плавно переходит в красный и разгорается, Bota щурится от яркости и морщит рот, звёздочек становится 4, у новых появляются маленькие спутники.
- **Отвечает:** зрачки двигаются как звуковая волна, ротик открывается.
- Объёмный стиль: мягкий свет на теле и руках, звезда-кристалл из 8 граней, блики в глазах, румянец. Падающей тени нет.
- Глаза — тёмные зрачки из очень тонких полосок-«радиоволн»: сами полоски не видны, только край слегка «дышит».
- Руки круглые (кулачок и ладошка без острых углов), внутренний край идёт строго параллельно звезде с одинаковым зазором. У пользователей с настройкой «уменьшить движение» анимации отключаются.
- Работает в любом современном браузере и с любым фреймворком (React, Vue, Tilda, WordPress и т.п.). Один файл ~20 КБ, без зависимостей.
