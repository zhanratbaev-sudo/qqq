# WebFor AI Assistant — плагин WordPress

AI-ассистент на сайте. Отвечает клиентам по вашей базе знаний (модель Claude Haiku 5.5 — быстрая и недорогая),
а сложные вопросы передаёт вам.

## Как работает

1. Клиент пишет в окно чата (кнопка «Спросить AI» в углу сайта).
2. Ассистент отвечает только по базе знаний и вашим прошлым ответам. Цены, сроки и факты, которых там нет, он не придумывает.
3. Если ответа нет, вопрос сложный или клиент просит человека — ассистент вызывает инструмент `escalate_to_owner`:
   вопрос появляется в **AI-ассистент → Вопросы** (с полным диалогом) и приходит вам на e-mail.
   Клиенту предлагается оставить телефон или написать в WhatsApp.
4. Вы пишете ответ в карточке вопроса. Кнопка «Отправить ответ клиенту в WhatsApp» открывает чат с готовым текстом,
   а галочка «Добавить в обучение» — и в следующий раз ассистент ответит на такой вопрос сам.

## Живой чат с менеджером

- Каждый разговор сохраняется. Когда ассистент передаёт вопрос, он сначала отвечает то, что знает,
  а чат получает статус «Ждёт вас» и вам приходит push-уведомление (и письмо).
- Подключиться и ответить можно в админке-приложении `/webfor-admin/` (плагин WebFor Site) → «Чаты».
  Клиент видит «Менеджер присоединился, сейчас ответит вам» и ваши сообщения с вашим именем.
- Окно чата у клиента само подтягивает новые сообщения (раз в несколько секунд), даже если он его закрыл — появится красная точка.
- Все вопросы клиентов считаются: «AI-ассистент → Частые вопросы» в админке.

## Установка

1. Нужен PHP 8.1 или новее.
2. Плагины → Добавить новый → Загрузить `webfor-ai.zip` → Активировать.
3. Ключ API: console.anthropic.com → API Keys → Create Key. Вставьте в **AI-ассистент → Настройки**
   или (надёжнее) в `wp-config.php`: `define('WFAI_ANTHROPIC_KEY', 'sk-ant-…');`
4. Проверьте и дополните **базу знаний** — услуги, цены, адреса, правила. Это главное «обучение».

Без ключа окно чата работает, но все вопросы сразу уходят вам.

## Настройки

- **Модель**: Haiku 5.5 (по умолчанию), Sonnet 5.5 или Opus 5.5 — сильнее и дороже.
- **Лимит**: сообщений в час с одного посетителя (защита от спама и лишних расходов).
- Телефон и WhatsApp берутся из плагина WebFor Site (WebFor → Настройки).

## Устройство

- `includes/chat.php` — REST: `POST /wp-json/webfor-ai/v1/chat` и `/contact`; запрос к Claude через официальную PHP-библиотеку `anthropic-ai/sdk`.
  Системная инструкция (правила + база знаний + выученные ответы) кэшируется.
- `includes/questions.php` — вопросы к владельцу, ответы, обучение.
- `includes/chats.php` — сохранённые разговоры, REST для менеджера `/wp-json/webfor-ai/v1/manager/*` и опрос `/poll` для окна чата, счётчик частых вопросов.
- `includes/push.php` — push-уведомления (Web Push, библиотека `minishlink/web-push`, ключи VAPID создаются сами).
- `includes/settings.php` — настройки и страница «Обучение».
- `assets/widget.js`, `assets/widget.css` — окно чата.

Собрать zip: `./build.sh` → `../webfor-ai.zip` (нужен composer).
