# WebFor AI Assistant — плагин WordPress

AI-ассистент на сайте. Отвечает клиентам по вашей базе знаний, а сложные вопросы передаёт вам.
Отвечать может **Gemini** (Google, есть бесплатный лимит — по умолчанию) или **Claude** (Anthropic, платно).

## Как работает

1. Клиент пишет в окно чата (кнопка «Спросить AI» в углу сайта).
2. Ассистент отвечает только по базе знаний и вашим прошлым ответам. Цены, сроки и факты, которых там нет, он не придумывает.
3. Если ответа нет, вопрос сложный или клиент просит человека — ассистент вызывает инструмент `escalate_to_owner`:
   вопрос появляется в **AI-ассистент → Вопросы** (с полным диалогом) и приходит вам на e-mail.
   Клиенту предлагается оставить телефон или написать в WhatsApp.
4. Вы пишете ответ в карточке вопроса. Кнопка «Отправить ответ клиенту в WhatsApp» открывает чат с готовым текстом,
   а галочка «Добавить в обучение» — и в следующий раз ассистент ответит на такой вопрос сам.

## Живой чат с менеджером

- Каждый разговор сохраняется. Когда ассистент передаёт вопрос, он сначала отвечает то, что знает,
  а чат получает статус «Ждёт вас» и вам приходит push-уведомление (и письмо).
- Подключиться и ответить можно в админке-приложении `/webfor-admin/` (плагин WebFor Site) → «Чаты».
  Клиент видит «Менеджер присоединился, сейчас ответит вам» и ваши сообщения с вашим именем.
- Окно чата у клиента само подтягивает новые сообщения (раз в несколько секунд), даже если он его закрыл — появится красная точка.
- Все вопросы клиентов считаются: «AI-ассистент → Частые вопросы» в админке.

## Голосовые сообщения

- В окне чата есть 🎤: клиент записывает голосовое (до минуты), Gemini его расшифровывает, ассистент отвечает как на текст.
  Нужен ключ Gemini (даже если отвечает Claude — Claude звук не принимает). Без ключа Gemini кнопки микрофона нет.
- У каждого ответа есть 🔊 — прочитать вслух голосом телефона (бесплатно). Если клиент спросил голосом, ответ читается сам.
- В «Чатах» голосовое видно текстом с 🎤.

## Мессенджеры: Telegram, WhatsApp, Instagram

Тот же ассистент (база знаний, готовые ответы, правила, передача менеджеру) отвечает в мессенджерах.
Разговоры приходят в админку-приложение → «Чаты» с пометкой канала; ответ менеджера уходит клиенту туда же.
Голосовые из Telegram и WhatsApp расшифровываются (нужен ключ Gemini).
Подключение — в админке: **Ещё → Мессенджеры** (там же пошаговые инструкции, адрес вебхука и проверочный ключ).

- **Telegram** — токен от @BotFather; вебхук ставится сам. С Telegram Premium бота можно подключить к личному аккаунту
  (Настройки → Telegram для бизнеса → Чат-боты) — тогда он отвечает за вас; на ваши собственные сообщения он не отвечает.
- **WhatsApp** — официальная WhatsApp Business Platform (Meta): Phone number ID, постоянный токен пользователя системы
  (права whatsapp_business_messaging), секрет приложения; в приложении Meta вебхук → `…/wp-json/webfor-ai/v1/meta`, поле `messages`.
  Отвечать можно в течение 24 часов после последнего сообщения клиента (правило Meta) — иначе в чате будет видно «не доставлено».
- **Instagram** — профессиональный аккаунт, «Instagram API с входом через Instagram» в том же приложении Meta, токен,
  тот же вебхук и проверочный ключ, подписка на `messages`.

Вебхуки: `POST /wp-json/webfor-ai/v1/telegram` (проверка заголовка секрета), `GET|POST /wp-json/webfor-ai/v1/meta`
(проверка verify token и подписи `X-Hub-Signature-256`). Повторы одного сообщения не обрабатываются дважды;
лимит сообщений в час — на каждого собеседника.

## Команды в чате

Работают на сайте и в мессенджерах (сообщение начинается с «/»):
- `/del` — очистить чат и начать заново (удобно для проверки); то же — `/new`, `/reset`, `/clear`.
- `/help` — список команд (`/menu`); `/manager` — позвать менеджера (`/human`); `/bot` — снова отвечает ассистент;
  `/status` — кто сейчас отвечает.
- Свои команды — в админке: **Обучение → Команды чата** (например `/price` → ваш текст с ценами).
  В Telegram команды на латинице появляются в меню «/».

## Установка

1. Нужен PHP 8.1 или новее.
2. Плагины → Добавить новый → Загрузить `webfor-ai.zip` → Активировать.
3. Ключ API в **AI-ассистент → Настройки**:
   - Gemini (бесплатно): aistudio.google.com → Get API key; ключ начинается с `AIza`.
     Можно в `wp-config.php`: `define('WFAI_GEMINI_KEY', 'AIza…');`
   - Claude (платно): console.anthropic.com → API Keys; `define('WFAI_ANTHROPIC_KEY', 'sk-ant-…');`
   Ключ Google, вставленный в поле Claude, плагин сам перенесёт в поле Gemini.
4. Проверьте и дополните **базу знаний** — услуги, цены, адреса, правила. Это главное «обучение».

Без ключа окно чата работает, но все вопросы сразу уходят вам.

## Настройки

- **Кто отвечает**: Gemini или Claude.
- **Модель Gemini**: `gemini-3.1-flash-lite` по умолчанию; можно вписать другую (начинается с `gemini-`).
  Бесплатный лимит Gemini ограничен и Google его меняет: когда он кончается, ассистент на сегодня передаёт вопросы вам
  (в вопросе будет причина «Закончился лимит Gemini»).
- **Модель Claude**: Haiku 5.5 (по умолчанию), Sonnet 5.5 или Opus 5.5 — сильнее и дороже.
- **Лимит**: сообщений в час с одного посетителя (защита от спама и лишних расходов).
- Телефон и WhatsApp берутся из плагина WebFor Site (WebFor → Настройки).

## Устройство

- `includes/chat.php` — REST: `POST /wp-json/webfor-ai/v1/chat` и `/contact`; запрос к Gemini — REST `generateContent`
  (функция `wfai_ask_gemini`), к Claude — через официальную PHP-библиотеку `anthropic-ai/sdk`.
  Системная инструкция (правила + база знаний + выученные ответы) кэшируется.
- `includes/questions.php` — вопросы к владельцу, ответы, обучение.
- `includes/chats.php` — сохранённые разговоры, REST для менеджера `/wp-json/webfor-ai/v1/manager/*` и опрос `/poll` для окна чата, счётчик частых вопросов.
- `includes/commands.php` — команды в чате (встроенные и свои), REST `/manager/commands`.
- `includes/channels.php` — Telegram, WhatsApp, Instagram: вебхуки, отправка, настройки `/manager/channels`.
- `includes/push.php` — push-уведомления (Web Push, библиотека `minishlink/web-push`, ключи VAPID создаются сами).
- `includes/settings.php` — настройки и страница «Обучение».
- `assets/widget.js`, `assets/widget.css` — окно чата.

Собрать zip: `./build.sh` → `../webfor-ai.zip` (нужен composer).
