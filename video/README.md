# Промо-видео PetGo для Reels / TikTok / WhatsApp

Готовое видео: `video/petgo-promo-mobile.mp4`. Формат 1080×1920 (9:16), MP4 (H.264 + AAC), ~52 сек, 13 сцен.

Как устроено:

1. `demo-site/` — локальная копия сайта: WordPress + плагин petgo-cabinet + демо-данные.
   Все имена и номера в демо-данных вымышленные, данных реальных клиентов в видео нет.
2. `scripts/record.mjs` — Playwright проходит сценарии в эмуляции iPhone 14 (390×844)
   и пишет клипы `clips/<сценарий>.mp4` в 2× разрешении.
3. `scripts/overlays.mjs` — рисует фон, рамку телефона и надписи (HTML → PNG, шрифт Inter Display Black).
4. `scripts/music.py` — генерирует фоновую музыку кодом, поэтому авторских прав на неё нет.
5. `scripts/build.mjs` — ffmpeg собирает сцены, анимирует надписи, делает переходы и сводит звук.

Надписи стоят над экраном телефона, в зоне 175–447 px, и не перекрывают интерфейс.
Сверху и снизу остаётся не меньше 150 px свободного места под кнопки соцсетей.

## Требования

- Node.js 20.12+, PHP 8 (с `pdo_sqlite`), Python 3 с `numpy`, `ffmpeg`, `unzip`
- `cd video && npm install && npx playwright install chromium`

## Поменять тексты и пересобрать (без новой записи)

Клипы уже лежат в `video/clips/`, поэтому для смены текстов перезаписывать экран не нужно.

1. Отредактируйте `video/scenes.json`:
   - `title` — надпись сцены. Слова в `*звёздочках*` выделяются жёлтым.
   - `duration` — длительность сцены в секундах (рекомендуем 3–5).
   - `clip`, `mark`, `start` — откуда брать кадры: клип, метка в нём и сдвиг от метки в секундах.
     Метки каждого клипа перечислены в `clips/<клип>.json`: `ready`, `submitted`, `saved` и т. п.
   - финальная сцена: `title`, `contacts` (список строк), `cta` (кнопка).
   - `transition` — переход в сцену: `fade`, `smoothleft`, `smoothup`, `slideleft`, `circleopen`
     и любые другие [переходы xfade](https://trac.ffmpeg.org/wiki/Xfade).
   - `brand` — цвета градиента и акцента, иконка для финала.
2. Пересоберите видео:

   ```bash
   cd video
   npm run build          # → video/petgo-promo-mobile.mp4, ~2 минуты
   ```

   Шрифт сам уменьшается, если надпись длинная (максимум 3 строки).
   Если общая длительность выйдет за 45–60 сек, скрипт выведет предупреждение.

## Перезаписать экран

```bash
cd video
npm run demo-site -- /путь/к/petgo-cabinet.zip   # поднять локальную копию на http://127.0.0.1:8080
npm run record                                   # сбросить демо-данные и записать все сценарии
npm run build
```

Сценарии: `home`, `site-request`, `login`, `pets`, `chat`, `staff`, `requests`.
Один сценарий можно перезаписать отдельно: `node scripts/record.mjs chat`.
Сценарии кабинета используют вход из сценария `login`, поэтому его нужно записать хотя бы один раз.

Демо-вход в кабинет: `owner` / `Demo-Owner-2026!`. Демо-данные задаются в `demo-site/seed.php`:
питомцы, заказы, заявки, сотрудники и чат.

Чтобы записать другой сайт, заполните `video/.env` по образцу `.env.example`.
Если на нём другие кнопки или поля, поправьте шаги в `flows` внутри `scripts/record.mjs`.
