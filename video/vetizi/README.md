# Vet.izi — промо-ролик (YouTube 16:9)

Готовое видео: `video/vetizi-promo.mp4`. Формат 1920×1080, 30 fps, 40 с.
Голоса нет: на экране надписи, звучат музыка и звуки действий (клики, клавиатура, уведомления, переходы).

Собрано на [HyperFrames](https://hyperframes.heygen.com): это HTML, GSAP и Three.js, которые рендерятся в MP4.

## Как устроен кадр

- **Слева — текст, справа — графика.** Текст стоит в колонке x 110–710 px, верх заголовка всегда на y = 380 px.
  Графика сцен находится только правее 760 px и не заходит под текст.
- **Все надписи ролика в одном файле — `compositions/captions.html`.** Параметры записаны в начале файла:
  - заголовок: Inter Display Black, 80 px, белый, одно слово или фраза выделены мятным `#3FE0A0`;
  - описание: Inter Display Bold, 34 px, `#A9BDB6`;
  - строки заголовка задаются явно через `<br>`, каждая не шире 600 px.
- **Каждая надпись задаётся группой** `<div class="cap-g" data-in data-out>`.
  У описаний `data-at` / `data-until` задают время смены — в том же стиле и на том же месте.

| Время | Сцена (графика) | Заголовок |
|---|---|---|
| 0–8.6 с | `stage3d.html` — 3D MacBook и телефон | Цифровые платформы для ветклиник → Сайт / Заявки / CRM / Чаты / Приложение → Vet.izi |
| 8.6–13 | `build.html` — код собирает сайт, затем сайт PetGo | Сайт под ваш дизайн |
| 13–17 | `request.html` — курсор заполняет форму | Заявки с сайта |
| 17–22.5 | `crm.html` — карточка садится в CRM, кадры кабинета | Следите за процессами |
| 22.5–28 | `phone3d.html` — 3D телефон, пуш-уведомления | Приложение для команды |
| 28–33 | `sites.html` — сайты разных бизнесов тасуются и раскладываются в сетку | Делаем бизнес удобнее → Добавим что нужно вам |
| 33–40 | `endcard.html` — 3D знак Vet.izi | Vet.izi — «Улучшаем бизнес и делаем процессы удобными» |

В сцене `sites.html` показаны **условные концепт-сайты** (ветклиника, груминг, салон красоты,
автосервис, кофейня) без названий брендов, плюс реальный пример — PetGo.
Их делает `scripts/make-sites.mjs`. Чтобы показать настоящие сайты, положите их скриншоты 1440×900
в `assets/shots/` и замените пути в `sites.html`.

## Звук

- **Музыка** — `scripts/music2.py`: синтез кодом, без авторских прав, ре минор, ~116 BPM.
  Удар и большой аккорд приходятся ровно на начало финала (33 с).
- **Звуки действий** — `scripts/sfx.py`, звуки CC0 из пакета uisfx лежат в `assets/sfx/`.
  Клики и набор текста берутся из событий, записанных в клипах (`assets/clips/*.json`, поле `events`).
  Уведомления, переходы и тасовка карточек расставлены по таймингу сцен (список `FIXED` в скрипте).

```bash
cd video/vetizi
python3 ../scripts/music2.py 40 assets/music.wav
python3 ../scripts/sfx.py .
```

Если меняете тайминг сцен, поправьте `SCENES`, `CODE_TYPING` и `FIXED` в `sfx.py`.

## Пересобрать видео

```bash
cd video/vetizi
npx hyperframes snapshot --at 2,11,25    # кадры для просмотра
npx hyperframes render -o ../vetizi-promo.mp4 -q delivery --video-frame-format png
```

`npx hyperframes check` на 3D-сцене телефона может упираться в свой таймаут в 120 с. Снимки кадров и рендер
при этом работают нормально.

## Перезаписать экраны продукта

Записи экрана и скриншоты снимаются с локальной копии сайта (`video/demo-site`, демо-данные):

```bash
cd video
./demo-site/setup.sh /путь/к/petgo-cabinet.zip   # поднять сайт на http://127.0.0.1:8080
php demo-site/seed.php demo-site/.wp             # сбросить демо-данные
node scripts/record-desktop.mjs                  # клипы с курсором и событиями → vetizi/assets/clips
node scripts/capture-stills.mjs                  # скриншоты для 3D-экранов → vetizi/assets/shots
```

После перезаписи метки времени в `assets/clips/*.json` могут сдвинуться.
Проверьте `data-media-start` и `data-playback-rate` у видео в `request.html` и `crm.html`, а также `SCENES` в `sfx.py`.
