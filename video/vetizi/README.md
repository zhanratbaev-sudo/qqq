# WebFor · Vet.izi — промо-ролик (16:9)

Готовое видео: `video/vetizi-promo.mp4`. Формат 1920×1080, 30 fps, 50 с, музыка и звуки интерфейса, без голоса.

WebFor — организация (сайт web.for.petgo.kz). Vet.izi — её продукт для ветклиник и бизнесов, которые помогают животным.
По референсу ролик идёт на экране ноутбука в тёмной комнате. Экран светится, на нём появляются логотип,
телефон и интерфейсы, а надписи поясняют каждое действие.

Собрано на [HyperFrames](https://hyperframes.heygen.com): это HTML, GSAP и Three.js, которые рендерятся в MP4.

## Как устроено

- `compositions/room.html` — 3D-комната: стол и MacBook, экран подсвечивает клавиатуру.
  Камера: общий план → наезд на экран → отъезд в финале.
- `lib/laptop.js` — общая формула камеры. Каждая сцена экрана сама ставит своё содержимое
  размером 1920×1247 ровно на дисплей ноутбука (`LAPTOP.mapScreen`) по общему времени ролика.
  Ключевые положения камеры задаёт массив `KEYS` в этом файле.
- `compositions/glow.html` — свечение экрана (бирюза и синий), общий фон всех сцен.
- `lib/vi3d.js → phone16` — iPhone 16 Pro в чехле цвета WebFor: на спинке лапки 🐾 и знак W,
  блок камер, Dynamic Island.
- `lib/phoneui.js` — экран телефона: главный экран, установка Vet.izi, раскрытие иконки, кадры приложения.
- `lib/caps.js` — единые надписи: заголовок Inter Display Black 96 px и описание 46 px.
  Колонка текста x 120–820 на экране ноутбука, графика правее 860.

| Время | Сцена | Что происходит |
|---|---|---|
| 0–7.5 с | `intro.html` | Экран оживает, логотип WebFor → «Представляем продукт» → Vet.izi |
| 7.5–16.5 | `phone.html` | Телефон выезжает снизу и покачивается (спинку не видно). На главном экране нет Vet.izi → приложение устанавливается → касание, иконка раскрывается → заявки, чат, сотрудники |
| 16.5–23 | `site.html` | Пишем код сайта → запускаем в терминале → готовый сайт (пример — PetGo) |
| 23–30 | `phone2.html` | Клиент заполняет форму на телефоне → телефон делает полный оборот (видно спинку с лапками) → «Заявка отправлена» |
| 30–39 | `crm2.html` | Заявка уже в CRM. Меню раскрывается при наведении курсора, как в кабинете. Дальше заказы, календарь, сотрудники, чаты |
| 39–44 | `sites2.html` | Сайты разных бизнесов тасуются и раскладываются в сетку, «+ модули» |
| 44–50 | `outro.html` | WebFor, «Vet.izi — наш продукт. Делаем бизнес удобнее», web.for.petgo.kz; камера отъезжает |

Тексты надписей лежат в HTML сцен: группы `.cap-g` с `data-in` / `data-out` (секунды ролика).

## Звук

```bash
cd video/vetizi
BAR=2.2 DROP_BAR=20 python3 ../scripts/music2.py 50 assets/music.wav   # удар на 44 с (такт 20)
python3 ../scripts/sfx.py .                                            # клики, клавиатура, переходы (CC0, uisfx)
```

Если меняете тайминг сцен, поправьте `SCENES`, `TYPING` и `FIXED` в `scripts/sfx.py`.

## Пересобрать видео

```bash
cd video/vetizi
npx hyperframes snapshot --at 3,12,27,33,46    # кадры для просмотра
npx hyperframes render -o ../vetizi-promo.mp4 -q delivery --video-frame-format png
```

## Записи экрана

- **Кабинет на компьютере** (`assets/clips/d-*.mp4`) записывает `video/scripts/record-desktop.mjs`,
  в том числе сценарий `d-menu` — меню, раскрывающееся при наведении.
- **Телефон** (`assets/seq/*`) — кадры из мобильных записей `video/clips/*.mp4`, их пишет `video/scripts/record.mjs`.
- **Локальный сайт** с демо-данными поднимается командой `video/demo-site/setup.sh /путь/к/petgo-cabinet.zip`.
