# WebFor · Vet.izi — промо-ролик (16:9)

Готовое видео: `video/vetizi-promo.mp4`. Формат 1920×1080, 30 fps, 50 с, музыка и звуки интерфейса, без голоса.

WebFor — организация (сайт web.for.petgo.kz). Vet.izi — её продукт для ветклиник и бизнесов, которые помогают животным.
Ролик идёт на весь кадр, без ноутбука. Градиент цвета WebFor не стоит фоном: он собирается в знак
и служит переходом. Из уходящего элемента (экрана телефона, окна) он на мгновение закрывает кадр
и сжимается в первый элемент следующей сцены.

Собрано на [HyperFrames](https://hyperframes.heygen.com): это HTML, GSAP и Three.js, которые рендерятся в MP4.

## Как устроено

- `lib/screen.js` — каждая сцена рисует содержимое 1920×1247, `SCREEN.map` ставит его в кадр 1920×1080
  по центру и медленно наезжает внутри сцены. Границы сцен — массив `SCENES`.
- `compositions/morph.html` — переходы. Массив `T`: момент полного закрытия кадра, прямоугольник «откуда»
  и «куда» (координаты сцены 1920×1247). Сцена напротив проявляет свой элемент, когда градиент в него сжался.
- `lib/vi3d.js → phone16` — iPhone 16 Pro в чехле цвета WebFor: на спинке лапки 🐾 и знак W,
  блок камер, Dynamic Island.
- `lib/phoneui.js` — экран телефона: главный экран, установка Vet.izi, раскрытие иконки, кадры приложения.
- `lib/caps.js` — единые надписи: заголовок Inter Display Black 96 px и описание 46 px.
  Колонка текста x 120–820, графика правее 860.

| Время | Сцена | Что происходит |
|---|---|---|
| 0–7.5 с | `intro.html` | Три пятна цвета WebFor стягиваются и застывают в плитку, W прорисовывается, «WebFor». Знак переворачивается: на обороте иконка Vet.izi, лапка отпечатывается по пальцам |
| 7.5–16.5 | `phone.html` | Телефон выезжает снизу. На главном экране нет Vet.izi → приложение устанавливается → касание, иконка раскрывается → заявки, чат, сотрудники |
| 16.5–23 | `site.html` | Экран телефона перетекает в окно редактора, пишется код, команды набираются в терминале, сайт открывается окном прямо из строки «Сайт запущен» |
| 23–30 | `phone2.html` | Браузер перетекает в экран телефона с формой. Клиент заполняет поля → телефон делает полный оборот (видно спинку) → «Заявка отправлена» |
| 30–39 | `crm2.html` | Экран телефона перетекает в окно CRM. Меню раскрывается при наведении курсора, дальше заказы, календарь, сотрудники, чаты |
| 39–44 | `sites2.html` | CRM перетекает в карточку сайта, карточки тасуются и раскладываются в сетку, «+ модули» |
| 44–50 | `outro.html` | Сетка перетекает в плитку WebFor, W прорисовывается, «Vet.izi — наш продукт. Делаем бизнес удобнее», web.for.petgo.kz |

Тексты надписей лежат в HTML сцен: группы `.cap-g` с `data-in` / `data-out` (секунды ролика).

## Звук

```bash
cd video/vetizi
BAR=2.4444 GROOVE_BAR=3 DROP_BAR=18 python3 ../scripts/music2.py 50 assets/music.wav   # ритм с 7.3 с (телефон), удар на 44 с
python3 ../scripts/sfx.py .                                            # звуки только на видимые действия (CC0, uisfx)
```

Если меняете тайминг сцен, поправьте `SCENES`, `TYPING` и `FIXED` в `scripts/sfx.py`.

## Пересобрать видео

```bash
cd video/vetizi
npx hyperframes snapshot --at 3,12,27,33,46    # кадры для просмотра
npx hyperframes render -o ../vetizi-promo.mp4 -q delivery --video-frame-format png
```

## Записи экрана

- **Кабинет на компьютере** (`assets/clips/d-*.mp4`) записывает `video/scripts/record-desktop.mjs`,
  в том числе сценарий `d-menu` — меню, раскрывающееся при наведении.
- **Телефон** (`assets/seq/*`) — кадры из мобильных записей `video/clips/*.mp4`, их пишет `video/scripts/record.mjs`.
- **Локальный сайт** с демо-данными поднимается командой `video/demo-site/setup.sh /путь/к/petgo-cabinet.zip`.
