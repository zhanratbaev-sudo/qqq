# Лапка Vet.izi (без надписей)

Обложки для «Актуального» в Instagram: 1080×1080, лапка по центру, поэтому круглая обрезка её не задевает.

| Файл | Фон / лапка |
|---|---|
| `vetizi-highlight-cream` | кремовый, как иконка Vet.izi / зелёная #0E7C6B |
| `vetizi-highlight-teal` | бирюзовый градиент WebFor / кремовая |
| `vetizi-highlight-dark` | тёмный #062019 / мятная #3FE0A0 |
| `vetizi-highlight-white` | белый / зелёная |
| `vetizi-paw` | прозрачный фон, только лапка |

Пересобрать: `python3 make-paw.py && node ../png.cjs .`
