# Логотип WebFor

| Файл | Где использовать |
|---|---|
| `webfor-mark.svg` / `.png` | знак: аватарка, иконка сайта и приложения (1024×1024) |
| `webfor-logo-on-dark.svg` / `.png` | знак + надпись на тёмном фоне (прозрачный PNG) |
| `webfor-logo-on-light.svg` / `.png` | знак + надпись на светлом фоне (прозрачный PNG) |
| `webfor-logo-dark-bg.svg` / `.png` | знак + надпись на чёрной подложке |

Цвета: плитка #19B39C → #0B6E63, буква W #F4F1E4, «For» на тёмном #3FE0A0, на светлом #0B6E63.
Шрифт надписи — Inter Display Black (в SVG переведён в кривые, шрифт ставить не нужно).

Пересобрать: `python3 make-logo.py` (нужен `pip install fonttools`).
