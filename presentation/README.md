Student: Nguyen Xuan Mai · Tourism Business / Taxation · 2026

## Files

| File | Purpose |
|---|---|
| `output/Saty_Guesthouse_Tax_Presentation.pptx` | Editable PowerPoint: every text, card and bar is a separate object |
| `output/Saty_Guesthouse_Tax_Presentation.pdf` | PDF with vector text, for printing and sending |
| `index.html` → `slides.html#present` | Presentation in the browser: ← → / Space to change slides, F for full screen |
| `slides.html` | **Source of the deck** (9 slides, 1920×1080). Edit the text here |
| `assets/kolsai-arch.png` | Cover illustration (dawn over Kolsai), generated by `tools/make_assets.js` |
| `tools/` | Generation scripts and PDF/PPTX export |

## Rebuild after editing

```bash
cd presentation
npm install
pip install playwright python-pptx pillow && python3 -m playwright install chromium
npm run build          # → output/*.pdf and output/*.pptx
```

## Design

Built following the method of the [huashu-design](https://github.com/alchaincyf/huashu-design) skill (MIT):
an HTML deck first, then a PDF, then an editable PPTX taken from the browser's rendered layout
(`tools/pptx_from_rendered.py` is a copy of that skill's script, patched to support two fonts and a custom Chromium path).

**Palette: soft pinks, sampled from the alpenglow over the Tien Shan at dawn**

| Role | Colour |
|---|---|
| Background (paper) | `#FFF8F8` |
| Petal (soft panels) | `#FCEEF1` |
| Blush (tints, tracks) | `#F6DCE3` |
| Rose (accent fills) | `#D58CA3` |
| Rose 600 (accent text) | `#B5607E` |
| Berry (headings, key numbers) | `#8C3A5B` |
| Plum (closing slide) | `#4E2338` |
| Ink (body text) | `#432C37` |
| Sage (the one complementary colour, "for Kazakhstan") | `#A9C1B1` / `#4F6E5C` |

- Fonts: **Cambria** for headings and **Calibri** for body text. Both ship with Microsoft Office, so the PPTX opens exactly as it was laid out.
- Motif: an arch window (the cover illustration), soft rounded cards, and pills.
- Every slide has one visual centrepiece:
  - grid of 10 rooms at 45% occupancy
  - revenue equation
  - break-even chart (40%)
  - price bars before and after VAT
  - VAT threshold gauge
  - tax collection points along the tourist's journey
  - the guest's bill
- Body text ≥ 24 px, labels ≥ 16 px, body-text contrast ≥ 4.5:1.

To use a real photo of Kolsai, replace `assets/kolsai-arch.png` with an image of the same proportions (744×920, arch-shaped), or change the picture in PowerPoint.
