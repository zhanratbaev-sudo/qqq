# StudyHub — плагины WordPress

Два плагина:

| Плагин | Что делает |
|---|---|
| **studyhub** (основной) | Приложение для студентов (PWA): главная, услуги, анонимный личный чат с вами, отзывы, выбор университета, русский и казахский языки. Вы управляете всем из админки WordPress. |
| **studyhub-ai** (отдельно) | ИИ-помощник на Google Gemini: вкладка «ИИ» в приложении. Предлагается студенту, если вы не в сети или долго не отвечаете. |

Готовые архивы лежат в `dist/`: `studyhub.zip` и `studyhub-ai.zip`.

## Установка

1. WordPress → **Плагины → Добавить новый → Загрузить плагин** → `studyhub.zip` → Активировать.
2. Затем то же самое для `studyhub-ai.zip`.
3. **Настройки → Постоянные ссылки** → нажмите «Сохранить» (один раз, чтобы заработал адрес `/app/`).
4. **StudyHub → Настройки**: название сайта (его видят студенты вместо вашего имени), логотип, цвет, тексты.
5. **StudyHub → ИИ-помощник**: вставьте API-ключ Gemini (aistudio.google.com → Get API key) и нажмите «Сохранить и проверить».

Приложение откроется по адресу `https://ваш-сайт/app/`. В настройках можно включить показ приложения на главной странице сайта. Есть также шорткод `[studyhub_app]`.

## Как это работает

**Вход для админа.** Вы входите в обычную админку WordPress (`/wp-admin`) своим логином и паролем WordPress. Пункт меню **StudyHub → Чаты**.

**Вход для студентов.** Регистрации нет.
- **StudyHub → Студенты (логины)** → «Создать». Логин и пароль можно задать вручную или сгенерировать, в том числе сразу несколько.
- Появится готовый текст «ссылка + логин + пароль» с кнопкой «Копировать». Отправьте его студенту.
- У каждого студента только анонимный ID вида `#4F2A`. Имён, телефонов и фото в системе нет. Заметку о студенте видите только вы.
- Студента можно заблокировать, выдать ему новый пароль или удалить вместе с перепиской и файлами.

**Чат.** Только личный: студент ↔ вы. Общего чата нет.
- Студент видит название сайта и логотип. Ваше имя и аккаунт WordPress не раскрываются.
- Можно отправлять файлы: фото, PDF, DWG, DOCX, ZIP, SKP и другие. У фото удаляются EXIF и геоданные.
- Файлы хранятся в закрытой папке `uploads/studyhub-private` и открываются только владельцу-студенту или вам.
- Есть галочки прочтения ✓✓ и счётчик непрочитанных в меню админки. По желанию можно включить уведомления на e-mail.
- Кнопка «Заказать» у услуги открывает чат с готовым сообщением и меткой услуги.

**Статус и ИИ-подстраховка.** В чатах вверху есть переключатель:
- **Авто**: вы «в сети», пока открыта страница «Чаты».
- **В сети**: всегда в сети.
- **Не в сети**: студенту сразу предлагается ИИ-помощник.

Если вы «в сети», но не ответили за N минут (настраивается, по умолчанию 5), студенту тоже предложат спросить ИИ. Его вопрос автоматически передаётся помощнику.

**Отзывы, только настоящие.**
- В чате нажмите **⭐ Попросить отзыв**. Студент получит карточку с оценкой и полем для текста.
- Оставить отзыв может только тот, кому вы отправили запрос, и только один раз на каждый запрос.
- Имя и фото не публикуются. Телефоны, e-mail, ссылки и @ники вырезаются автоматически. Подпись выглядит так: «Студент · КазГАСА».
- Отзывы проходят модерацию в **StudyHub → Отзывы**. Можно включить публикацию без модерации.

**Услуги и университеты.** Редактируются в **StudyHub → Услуги и вузы**.
- По умолчанию заданы четыре услуги: домашние задания, макеты, рисунки, чертежи.
- По умолчанию заданы два вуза: ALT и КазГАСА.
- Тексты вводятся на русском и казахском. Если поле цены пустое, на карточке будет «Цена — в чате».

## Как «скачать» приложение (PWA)

- **iPhone**: открыть `/app/` в Safari → «Поделиться» → «На экран „Домой“».
- **Android**: Chrome предложит «Установить приложение», или в профиле есть кнопка «Установить приложение».

После установки приложение открывается без адресной строки, со своей иконкой. Нужен HTTPS.

## Безопасность и приватность

- Пароли студентов хранятся только в виде хеша, как у WordPress. Сессия хранится в HttpOnly-cookie, действует 90 дней.
- После 6 неудачных попыток входа с одного IP вход блокируется на 15 минут.
- **nginx**: файл `.htaccess` там не работает. Добавьте в конфиг:
  `location ^~ /wp-content/uploads/studyhub-private/ { deny all; }`
  Без этого файлы всё равно защищены случайными 32-символьными именами, но правило надёжнее.
- Переписка с ИИ не сохраняется на сервере. В Gemini уходит только текст вопросов, без логина и ID.
- Удаление плагина не удаляет данные, пока вы не включите это в настройках.

## Требования

WordPress 6.0+ и PHP 7.4+. Сборка не нужна: чистые PHP, JS и CSS.
