# StudyHub — 4 плагина WordPress

Устроено как PetGo: ядро плюс отдельные плагины, каждый обновляется сам по себе. Дизайн свой: стекло, оранжевый акцент, стиль iOS.

| Плагин | Что делает | Адрес |
|---|---|---|
| **StudyHub Ядро** (`studyhub-core`) | База данных, API для плагинов, общий дизайн (`ui.css`, `ui.js`), PWA. **Админ-панель — отдельная страница-приложение, а не wp-admin**: чаты, студенты (логины), отзывы, услуги и вузы, настройки, разделы плагинов | `/panel/` |
| **StudyHub Сайт** (`studyhub-site`) | Публичный сайт без темы WordPress: Главная, Услуги, Отзывы, «Войти». Русский и казахский, SEO | `/`, `/uslugi/`, `/otzyvy/` |
| **StudyHub Студент** (`studyhub-client`) | Кабинет студента: вход по выданному логину, заказ услуги, анонимный чат, файлы, отзыв по приглашению, выбор вуза | `/app/` |
| **StudyHub ИИ** (`studyhub-ai`) | ИИ-помощник на Gemini: вкладка «ИИ» у студента и подсказка в чате, когда вы не в сети или долго не отвечаете. Несколько ключей по кругу, запасные модели, база знаний. Настройки — в панели | — |

Архивы для загрузки лежат в `dist/*.zip`. Ядро обязательно, остальные плагины — по желанию. Без «Студента» студенты не смогут войти.

## Установка
1. «Плагины → Добавить новый → Загрузить». Сначала загрузите `studyhub-core.zip`, затем `studyhub-site.zip`, `studyhub-client.zip` и `studyhub-ai.zip`. Активируйте все.
2. «Настройки → Постоянные ссылки» → «Сохранить» (один раз).
3. Откройте **`https://ваш-сайт/panel/`** и войдите логином и паролем администратора WordPress.
4. В панели:
   - **Настройки** — название сайта (его видят студенты вместо вашего имени), логотип, ссылка «Получить доступ» (Telegram или WhatsApp);
   - **ИИ-помощник** — вставьте ключ Gemini и нажмите «Сохранить и проверить».

## Админ-панель `/panel/`
- **Вход.** Своя страница входа, логин и пароль WordPress, только для администратора. После 5 неудачных попыток вход блокируется на 15 минут. Вход помнится 60 дней.
- **Вид.** На компьютере меню слева, на телефоне — нижние вкладки. Панель можно добавить на экран «Домой» как приложение.
- **Чаты.**
  - Список чатов с поиском.
  - Заметка о студенте — её видите только вы.
  - Файлы, отметки прочтения ✓✓, кнопка «Отзыв».
  - Статус: Авто / В сети / Нет. При «Нет» студенту сразу предлагается ИИ.
- **Студенты.**
  - Выдача логина, можно сразу нескольких.
  - Готовый текст «ссылка + логин + пароль» с кнопкой «Копировать».
  - Новый пароль, блокировка, удаление.
- **Отзывы.** Вкладки «На проверке» и «Опубликованные», средняя оценка.
- **Услуги и вузы.**
  - Тексты на русском и казахском, иконка и цвет карточки.
  - Цена необязательна: если поле пустое, показывается «Цена — в чате».
  - Вузы со значками.
- **Настройки.**
  - Бренд, баннер, приветствие в чате.
  - Через сколько минут предлагать ИИ, максимальный размер файлов.
  - Адреса `/app/` и `/panel/`, показ сайта на главной.
- В wp-admin остаётся только пункт «StudyHub» со ссылкой на панель.

## Анонимность
- У студента только ID вида `#4F2A`.
- Ваше имя нигде не показывается, только название сайта.
- С фото удаляются EXIF и геоданные. Файлы чатов лежат в закрытой папке.
- Отзывы публикуются без имени и фото. Телефоны, e-mail и ссылки вырезаются автоматически.
- Переписка с ИИ на сервере не хранится.

Для nginx добавьте в конфиг `location ^~ /wp-content/uploads/studyhub-private/ { deny all; }`.
