# PetGo Маркет — интернет-магазин (HTML, CSS, JS)

Прототип магазина в дизайне PetGo 27.0.0, без сборки и без зависимостей.

| Файл | Что это |
|---|---|
| `index.html` | Витрина в стиле сайта PetGo: меню, главный экран, каталог с категориями, окно товара, корзина, оформление заказа |
| `admin.html` | Панель магазина в стиле кабинета PetGo 27 (iOS 27): товары и заказы |
| `css/shop.css` | Стили витрины: `#FBF9E8`, `#024C46`, Manrope, карточки 20 px, кнопки 14 px |
| `css/admin.css` | Стили панели: Liquid Glass, крупный заголовок, капсулы, лист снизу, тёмная тема |
| `js/store.js` | Общие данные: товары, категории, заказы, корзина |
| `js/shop.js` | Логика витрины |
| `js/admin.js` | Логика панели: добавление и редактирование товаров с фото, удаление, заказы |

## Как запустить

Откройте папку через любой локальный сервер, например:

```bash
cd shop && python3 -m http.server 8000
# витрина:  http://localhost:8000/
# панель:   http://localhost:8000/admin.html
```

## Как добавить товар онлайн

1. В панели нажмите круглую кнопку «+».
2. Добавьте фото (до 8, можно перетащить). Первое фото — обложка, ★ делает фото обложкой.
3. Заполните название, категорию, описание, цену (и старую цену для скидки), «В наличии».
4. Нажмите «Опубликовать». Товар сразу появится на витрине, даже в уже открытой вкладке.

Фото сжимаются прямо в браузере до 1200 px (JPEG 82%).
Заказы с витрины появляются во вкладке «Заказы» с кнопками «Написать / Позвонить» и «Выполнен».

## Важно: это прототип

Данные хранятся в `localStorage` браузера, поэтому:

- товары и заказы видны только в этом браузере на этом устройстве;
- места мало — около 5 МБ, это примерно 30–50 фото;
- у панели нет входа по паролю.

Для настоящего магазина `js/store.js` нужно заменить запросами к серверу. Например, сделать WordPress-плагин
по образцу `petgo-cabinet`: товары в базе, фото в медиатеке, вход сотрудников, уведомления о заказах.
Интерфейс и стили при этом остаются теми же.
