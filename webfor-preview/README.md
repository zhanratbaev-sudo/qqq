# Предпросмотр сайта WebFor

`index.html` — одна страница для просмотра сайта без WordPress (опубликована как артефакт в чате).
Собирается из готовой страницы локального WordPress с плагинами `webfor-site` и `webfor-ai`:

```bash
curl -s http://127.0.0.1:8090/ > /tmp/page.html   # локальный сайт
python3 build.py /tmp/page.html
```

В предпросмотре форма заявки никуда не уходит, а ассистент отвечает через Claude зрителя по той же базе знаний (`ai.json`).
