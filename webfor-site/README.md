# WebFor Site — плагин WordPress

Сайт WebFor целиком в одном плагине: тёмный дизайн без градиентов, услуги (сайты, мобильные приложения, AI-чат-боты, Izi),
Izi (Vet.izi и Izi с AI-ассистентом),
таблица сравнения, шаги работы, вопросы и форма заявки внизу.

## Установка

1. WordPress → Плагины → Добавить новый → Загрузить плагин → `webfor-site.zip` → Активировать.
2. Плагин сам создаёт страницу «WebFor». Если на сайте главной была лента записей, эта страница становится главной.
   Иначе откройте её по ссылке из WebFor → Настройки или назначьте главной в Настройки → Чтение.
3. Сайт можно вставить на любую страницу шорткодом `[webfor_landing]` — страница откроется во весь экран, без шапки темы.

## Папки с работами

Блок «Что мы делаем» — четыре папки: Сайты, Мобильные приложения, AI-чат-боты, Izi. Из папок торчат карточки.
По нажатию папка «вырастает» в отдельную страницу с работами (адреса `#sites`, `#apps`, `#bots`, `#izi` — можно дать ссылку прямо на папку).
Кнопка «Все услуги», жест «назад» или Esc возвращают на сайт. Карточку можно открыть крупно, листать и перейти на сайт.

Работы правятся в **WebFor → Работы**: название, папка, вид скриншота (сайт или телефон), метка («Наш проект», «Концепт»),
описание, ссылка, скриншот (блок «Скриншот» справа) и порядок. При первой активации добавляются примеры:
PetGo, Oscar Clinic, концепты сайтов, приложение PetGo для сотрудников, концепты приложений и чат-ботов, экраны Vet.izi.
Для Oscar Clinic пока стоит обложка без скриншота — загрузите настоящий скриншот в карточке работы.

## AI-ассистент

Отдельный плагин `webfor-ai` (см. его README). Если он включён, на первом экране появляется кнопка «Спросить AI-ассистента».

## Панель управления

Одна и та же панель открывается в админке WordPress (пункт **WebFor**) и отдельным приложением на телефоне (`/webfor-admin/`).
Сделана в первую очередь для телефона: стеклянная панель внизу, листы снизу, большие заголовки, плавные переходы.
Четыре раздела:
- **Чаты** — разговоры с ассистентом; «Ждут вас» — ассистент позвал менеджера. Присоединиться, ответить, вернуть ассистенту.
- **Заявки** — Новые / В работе / Готово, кнопки «Позвонить» и «WhatsApp», статус и удаление — по нажатию на заявку.
- **Обучение** — проверка ассистента (спросить как клиент), вопросы, на которые нужен ваш ответ, частые вопросы,
  «Что знает ассистент» (база знаний темами: добавить, изменить, загрузить из .txt) и готовые ответы.
- **Ещё** — уведомления, телефон и WhatsApp на сайте, работы в папках, выход.

## Админка-приложение /webfor-admin/ (PWA) и живой чат

Та же панель на весь экран в дизайне сайта: `https://ваш-сайт/webfor-admin/` (вход — логин администратора WordPress).
Если постоянные ссылки выключены, адрес такой: `https://ваш-сайт/?webfor_app=page`.

- **Чаты** — все разговоры с AI-ассистентом. Сверху «Ждёт вас» — ассистент позвал менеджера.
  «Присоединиться» → клиент видит «Менеджер присоединился, сейчас ответит вам», ваши сообщения подписаны именем
  из настроек ассистента (по умолчанию «Нуржан»). Пока вы в чате, ассистент молчит. «Вернуть ассистенту» — он снова отвечает.
- **AI-ассистент → Частые вопросы** — все вопросы клиентов, самые частые сверху; ответ одной кнопкой уходит в обучение.

**Установить на телефон и включить уведомления**
1. iPhone: откройте `/webfor-admin/` в Safari → «Поделиться» → «На экран Домой». Откройте админку со значка
   (на iPhone уведомления работают только так, iOS 16.4+).
   Android: Chrome → меню → «Установить приложение».
2. В приложении: «Чаты» → «🔔 Включить уведомления» → разрешить. Кнопка «Проверить» пришлёт тестовое уведомление.
3. Когда ассистент зовёт менеджера (или клиент пишет в чат, где вы уже есть), приходит уведомление — нажмите, откроется нужный чат.

Сайт должен работать по HTTPS — без него браузеры не дают ставить приложение и присылать уведомления.

## Телефон и WhatsApp

WebFor → Настройки:
- **Телефон для звонков** — номер в шапке, подвале, кнопках «Позвонить».
- **Номер WhatsApp** — все кнопки «WhatsApp».
- **Текст сообщения в WhatsApp** — подставляется в чат.

Поля независимы: поменяли телефон — WhatsApp остался прежним, и наоборот. Номер с ошибкой (меньше 10 цифр) не сохранится.
Номера можно вывести где угодно: `[webfor_phone]`, `[webfor_whatsapp]`.

## Заявки

WebFor → Заявки: имя, телефон, услуга, как связаться (звонок или WhatsApp), комментарий, статус (Новая / В работе / Готово).
Количество новых заявок видно в меню. Если указан e-mail для уведомлений и на сайте работает почта — придёт письмо.
Защита: поле-ловушка для ботов, проверка nonce, не больше 5 заявок в час с одного адреса. Без JavaScript форма тоже работает.

## Файлы

- `webfor-site.php` — подключение, активация (страница, настройки по умолчанию)
- `includes/settings.php` — настройки и функции номеров
- `includes/leads.php` — заявки: приём формы, список, статус, письмо
- `includes/render.php` — шорткоды, шаблон страницы, иконки
- `templates/landing.php` — разметка сайта, `assets/site.css`, `assets/site.js`

Собрать zip: `./build.sh` → `../webfor-site.zip`.
