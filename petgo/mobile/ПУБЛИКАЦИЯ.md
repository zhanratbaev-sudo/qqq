# My PetGo: как опубликовать в Google Play и App Store

Приложение для клиентов PetGo. Внутри — кабинет клиента с сайта (`https://petgo.kz/lk/`). Всё, что вы меняете на сайте, сразу появляется в приложении. Заново публиковать приложение нужно только при изменении самой оболочки: значка, названия, разрешений.

Приложение добавляет к сайту:
- уведомления на телефон: «Няня у двери — покажите QR-код», «Заказ подтверждён», «Прогулка началась», «Мурка дома», ответы менеджера; нажатие открывает нужный экран;
- заставку с лапкой PetGo, экран «Нет интернета» с кнопкой «Повторить»;
- вибрацию, когда няня отсканировала QR;
- кнопку «Назад» на Android: закрывает окно, потом возвращает на главную, потом сворачивает приложение;
- договор и страницы сайта открываются во встроенном браузере, WhatsApp и eGov — в своих приложениях;
- вход для сотрудников, реклама и счётчики в приложении не показываются.

## Что уже готово

| Файл | Для чего |
|---|---|
| `my-petgo-1.0.0.aab` | загрузить в Google Play |
| `my-petgo-1.0.0.apk` | установить на свой Android и проверить |
| `mypetgo-upload.jks` и `keystore.properties` | ключ подписи Android и пароль. **Храните в надёжном месте**, без них не выпустить обновление (Google может заменить ключ по заявке, но это долго) |
| `store/appstore/` | скриншоты 1320×2868 и значок 1024 для App Store |
| `store/googleplay/` | скриншоты 1080×1920, значок 512, баннер 1024×500 |
| `store/ТЕКСТЫ.md` | названия, описания, ключевые слова, ответы на анкеты магазинов |
| `ios/` | проект для iPhone, собирается на Mac или в GitHub (шаг 4) |

## Шаг 0. Обновите плагины на сайте до 37.0

«PetGo Кабинет», «PetGo Клиент», «PetGo Сайт» 37.0.0. Без них не будет уведомлений, политики конфиденциальности (`/privacy/`) и настроек «Приложение My PetGo».

Проверьте, что страница https://petgo.kz/privacy/ открывается и в ней верные реквизиты. Они берутся из Настройки → «Договор с клиентами».

## Шаг 1. Демо-аккаунт для проверки

Apple и Google проверяют приложение вручную, им нужен вход.

1. Зарегистрируйте в кабинете клиента, например логин `review`, пароль от 8 символов.
2. Добавьте питомца с фото. Хорошо бы сделать 1–2 завершённых заказа, чтобы были прогулки и отчёт.
3. Логин и пароль впишите в анкеты обоих магазинов (см. `store/ТЕКСТЫ.md`). Аккаунт не удаляйте.

## Шаг 2. Уведомления: Firebase (Android) и ключ Apple (iPhone)

**Android (Firebase, бесплатно)**
1. https://console.firebase.google.com → «Создать проект» → PetGo (Google Analytics можно выключить).
2. «Добавить приложение» → Android → имя пакета `kz.petgo.my` → скачайте **google-services.json**.
3. Пришлите этот файл мне, и я пересоберу Android-версию с уведомлениями. Или сами положите его в `mobile/android/app/` и соберите.
4. Настройки проекта → «Сервисные аккаунты» → «Создать закрытый ключ» → откройте .json → скопируйте всё → приложение сотрудников → Настройки → «Приложение My PetGo» → «Android — Firebase» → «Сохранить».

**iPhone (после шага 4а)**
1. developer.apple.com → Certificates, IDs & Profiles → **Keys** → «+» → отметьте **Apple Push Notifications service (APNs)** → скачайте `AuthKey_XXXXXXXXXX.p8`. Скачать можно только один раз.
2. Настройки → «Приложение My PetGo» → «iPhone — Apple»: вставьте текст .p8 целиком, Key ID (10 символов), Team ID (Membership → Team ID) → «Сохранить».
3. Проверка: войдите в приложение демо-клиентом, разрешите уведомления → «Отправить тестовое уведомление».

## Шаг 3. Google Play

1. **Аккаунт разработчика**: https://play.google.com/console, оплата 25 $ один раз. Нужна проверка личности.
   - **Личный аккаунт**: перед выпуском для всех нужен закрытый тест — **12 тестировщиков в течение 14 дней** (друзья, сотрудники, клиенты с Android; им приходит ссылка на установку).
   - **Аккаунт организации** (нужен номер D-U-N-S, бесплатно на dnb.com): такого требования нет.
2. «Создать приложение» → название **My PetGo**, язык по умолчанию — русский, «Приложение», «Бесплатное».
3. **Тестирование → Закрытое тестирование** → создать выпуск → загрузите `my-petgo-1.0.0.aab`. Google предложит **подписание приложений Google Play**: соглашайтесь. Ваш ключ `mypetgo-upload.jks` — это ключ загрузки.
4. **Основная страница** (Store listing): тексты, значок, баннер и скриншоты из `store/`.
5. **Содержание приложения**: ответы в `store/ТЕКСТЫ.md` (политика, доступ с демо-аккаунтом, реклама — нет, рейтинг, аудитория 18+, безопасность данных, удаление аккаунта).
6. Добавьте тестировщиков (списком почт Google) → отправьте выпуск на проверку. Проверка обычно занимает от нескольких часов до нескольких дней.
7. Через 14 дней (для личного аккаунта) → «Рабочая версия» → «Подать заявку на доступ» → выпуск для всех.

## Шаг 4. App Store

**а) Аккаунт**: https://developer.apple.com/programs/, 99 $ в год. Можно как физлицо: в магазине будет ваше имя. Или как организация: нужен D-U-N-S, в магазине будет название компании.

**б) ID приложения**: Certificates, IDs & Profiles → Identifiers → «+» → App IDs → App → описание `My PetGo`, Bundle ID **Explicit** `kz.petgo.my` → отметьте **Push Notifications** → Register.

**в) Карточка**: https://appstoreconnect.apple.com → Приложения → «+» → «Новое приложение»: iOS, имя **My PetGo**, язык русский, Bundle ID `kz.petgo.my`, SKU `mypetgo`.

**г) Сборка — один из двух способов**

*Без Mac, через GitHub (рекомендую):*
1. App Store Connect → Users and Access → **Integrations** → App Store Connect API → «+» → имя `GitHub`, доступ **Admin** → скачайте `.p8`, запишите **Key ID** и **Issuer ID**.
2. GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `APPLE_TEAM_ID`: Team ID;
   - `ASC_KEY_ID`: Key ID;
   - `ASC_ISSUER_ID`: Issuer ID;
   - `ASC_KEY_P8`: содержимое .p8 целиком.
3. GitHub → **Actions** → «My PetGo — iOS» → **Run workflow**. Кнопка появляется, только когда эта ветка слита в основную (`main`): GitHub запускает такие сборки из основной ветки. Через 15–30 минут сборка появится в App Store Connect → TestFlight. Каждый запуск даёт новый номер сборки.

*С Mac:* установите Xcode и Node.js → в папке `petgo/mobile`: `npm ci`, затем `npm run ios:open` → в Xcode: App → Signing & Capabilities → Team (ваш) → Product → **Archive** → Distribute App → App Store Connect → Upload.

**д) Страница в App Store**: скриншоты из `store/appstore/` (раздел iPhone 6,9″), подзаголовок, описание, ключевые слова, URL поддержки и политики, категория «Образ жизни», возраст 4+. Тексты — в `store/ТЕКСТЫ.md`.

**е) App Privacy**: ответы в `store/ТЕКСТЫ.md`. Отслеживания нет.

**ж) App Review Information**: демо-логин и пароль, текст для проверяющего (в `store/ТЕКСТЫ.md`, по-английски) → выберите сборку → **Отправить на проверку**. Проверка обычно занимает 1–3 дня.

## Если Apple отклонит

- **4.2 «Minimum Functionality»** (приложение похоже на сайт). В ответе (Resolution Center) перечислите, что делает только приложение: уведомления о передаче питомца с автоматическим открытием QR-кода, вибрация при сканировании, работа без браузерного интерфейса, экран «Нет интернета», нативная кнопка «Назад». Обычно этого достаточно. Если нет — напишите мне, добавлю нативные функции.
- **5.1.1(v) — удаление аккаунта**: уже есть («Аккаунт» → «Удалить кабинет»).
- **2.1 — нет доступа**: проверьте, что демо-аккаунт входит и пароль верный.

## Обновления приложения

- Изменения на сайте и в кабинете появляются в приложении сразу, публиковать ничего не нужно.
- Новая сборка (значок, название, новые разрешения): в `mobile/petgo.config.json` увеличьте `version` (например `1.0.1`) и `build` (на 1) → соберите (GitHub Actions: «My PetGo — Android» / «My PetGo — iOS», номер сборки растёт сам) → загрузите в магазины.

## Для разработчика

```
cd petgo/mobile
npm ci
npm run sync          # подготовить проекты Android и iOS
npm run android:aab   # Android: .aab для Google Play (нужен android/keystore.properties)
npm run android:apk   # Android: .apk для установки
npm run ios:open      # iOS: открыть в Xcode (только на Mac)
npm run assets        # пересоздать значки и заставки из mobile/assets/
```
Адрес кабинета, ID, название и версия — в `petgo.config.json`. Capacitor 8, Android target SDK 36, iOS 15+, только iPhone (без iPad: не нужны скриншоты для iPad).
