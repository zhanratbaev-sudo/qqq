# PetGo ИИ 34.0

ИИ‑помощник для сайта PetGo. Работает **вместе** с плагином «PetGo Кабинет» (сайт и приложение).

**34.0:** в кабинете клиента на сайте помощник здоровается по имени и знает питомцев клиента, их статус и последние прогулки (данные передаёт «PetGo Кабинет» 34.0 подписанной меткой).

Устроен так же, как Oscar Clinic AI.

## Установка
1. Установите и включите сначала **PetGo Кабинет**, затем **PetGo ИИ**.
2. WordPress → **Настройки → PetGo ИИ**: вставьте ключ Gemini (aistudio.google.com → Get API key, бесплатно) → «Сохранить и проверить».
3. Модель по умолчанию — `gemini-3.1-flash-lite` (есть бесплатный лимит). Если модель недоступна или исчерпан лимит — плагин сам переключится на следующую.

## Как работает
* Кнопка «Помощник» — в центре нижнего меню сайта. Если плагин выключить, кнопка исчезнет, а сайт продолжит работать.
* Ответ «печатается» по мере генерации. Можно отправить голосовое сообщение — оно расшифровывается в текст.
* Знания берутся из сайта автоматически: услуги, цены, скидка, тексты первого экрана, частые вопросы, отзывы, контакты.
  Дополнительные знания — «База знаний» на странице настроек.
* Можно добавить сколько угодно запасных ключей с разных аккаунтов Google: сообщения делятся между ними по кругу,
  «уставший» ключ отдыхает, а запрос сразу уходит на следующий.
* «Оставить заявку» из чата открывает форму сайта, имя и телефон из разговора подставляются сами.
* Если клиент просит человека или ИИ не знает ответа — чат появляется в приложении PetGo → **«Чаты с сайта»**,
  сотрудникам приходит уведомление, ответ менеджера клиент видит прямо в чате.
* Последняя ошибка Google показывается на странице настроек.
